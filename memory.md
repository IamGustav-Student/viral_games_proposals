# Memoria del Proyecto: Juegos Virales e Ingresos

## Objetivo
Encontrar propuestas de juegos virales que generen ingresos rápidos para invertir en la suscripción de Antigravity, separando este trabajo del proyecto principal L2 Meraki.

## Estado Actual
- Se ha investigado tendencias de 2024-2025 (Telegram Mini Apps, TikTok Games).
- Se ha desglosado la lista completa de actividades de Lineage 2 como base de inspiración.
- **Novedad:** Se ha definido "PROJECT: NEO-RIFT" como el primer minijuego clave, usando una temática post-apocalíptica moderna.
